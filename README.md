# TT Trucking Calculator

A trucking and crafting calculator for Transport Tycoon, with storage tracking and in-game integration.

Run `npm ci`, then `npm start` to build and serve locally. Use `npm run build` to create the deployable files in `dist/`.

Enter your User ID and API key to load your storages. Settings and the API key are saved in your browser's local storage.

Each app load sends a generic usage event without a player name or identifier. Load counts do not represent unique users.
